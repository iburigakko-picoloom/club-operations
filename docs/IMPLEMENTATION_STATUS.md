# 実装状況 — 0.9

## v0.9の追加

LINEログイン／アカウント連携のコードは追加済み、実設定は無効。state・nonce・PKCE・IDトークン検証・自前セッション・既存アカウントの明示連携を実装した。LINEとの外部通信はテストで差し替え、実認証は未検証。

ログイン前／グループ選択／アカウント／招待の受け取り・発行・無効化／メンバー単位の権限設定を追加した。配車の往復切替、コピー確認、画像保存共有、予定の画像対象選択を改善した。グループ内5タブ・幹部予定表示・現行練習メニューは維持。

詳細は `CODEX_HANDOFF_v0.9.md`、検証結果はルート `QA_REPORT.md` を参照。

## 練習メニューの現行版と旧版の扱い

現行の正本は公開GitHub `manatocookietwitter-lang/training-menu-app` の `main`、確認時HEAD `53d7258`。直前の `b9466eb` で3段階フロー、`セットあり/1回のみ`、分類/履歴編集モード、Undo、画像保存時の履歴追加が導入されたため、統合版もこれへ追従した。計算は各人数パターンごとに `秒数 × set数 × 人数`、1回のみの種目は固定秒数を1回加える。

`references/training_menu_legacy.html` は移行回帰用に残す。旧5人基準の互換フィールドは200組で回帰確認するが、現在UIの合計時間を旧5人基準1値へ戻さない。保存済み表と履歴はメニューマスターから独立したスナップショットで、後からマスターを編集しても過去内容を変えない。

## 今回作っていないもの・確認できていないもの

LINEの実チャネル作成・秘密設定・実端末での認証往復は行っていない。アカウント削除／LINE連携解除と認可取消の運用、LINE認証経路の本番レート制限・監視、メールからの移行運用はCodexで仕上げる。詳細は新しい引き継ぎ文書を参照。


1. **予定Siteの現在デプロイソースとのコード単位の完全差分。** 公開URLは特定済みだが、この環境からSiteソースを直接取得できていない。
2. 公開URLへの配置、既存GitHubへのコミット/PR。いずれも行っていない。
3. iPhone/Android実機でのインストール・ブラウザー差・通知到達・OS共有シート。
4. Pushライブラリの実環境導入と実送信。予約計算・取消は実DBでテスト済み。
5. パスワードのメール再発行・メール所有確認・汎用会員サービス運用。
6. 自動無期限反復、既に生成したシリーズ全体をまとめて変更するUI。
7. 高負荷/大人数/数年の大量履歴、全端末アクセシビリティ監査、第三者セキュリティ監査。
8. 実ブラウザーの永続StorageとService Worker更新の端末横断試験。
9. 業務データJSONの全体復元UI。書出しとサーバーDBバックアップは実装済み。

## 意図的な対象外

一般部員へのログイン強制、会計/部費、体育館料金、在庫の入出庫帳簿、既読管理、自由配置ホーム、運転者の事前一括選択画面、AIによる自動練習作成は実装対象外です。

## 公開判定
